# NEXORA

![Nexora](.github/images/Yvonne%28Arknights-Endfield%29.jpg)

![CI](https://github.com/KyomuTenshi/Nexora-DevBuild/actions/workflows/ci.yml/badge.svg)

> *Аниме и манга в одном месте: смотри, читай, отмечай прогресс и собирай профиль, которым хочется поделиться.*

Мобильное приложение для аниме и манги на Flutter/Dart. Современная архитектура, поддержка оффлайн-режима, синхронизация с облаком, интерактивные карты, кастомизация профиля и нативные возможности устройств.

---

## Общее

| | |
|---|---|
| **Тип** | Мобильное приложение: каталог, библиотека и профиль для аниме и манги |
| **Фреймворк** | Flutter / Dart (Flutter 3.47+, Dart 3.13+) |
| **Платформа** | Android (основная). iOS: интерфейс и локальная часть работают, облачные и нативные функции не настроены (см. «Известные ограничения») |
| **Источники данных** | Kitsu REST API (Jikan как запасной), OpenStreetMap Overpass API для «Рядом» |
| **Облако** | Firebase: Authentication, Cloud Firestore, Cloud Messaging, Crashlytics |
| **Языки** | Русский, английский |
| **Разработчик** | Piperite Games |

---

## Цель и аудитория

**Цель.** Сделать место, где удобно смотреть аниме и читать мангу: быстро найти тайтл, понять, о чём он, продолжить с того места, где остановился, и держать весь прогресс в одной библиотеке.

**Аудитория.** Зрители и читатели аниме и манги, которым нужен один удобный каталог и личный список вместо отдельных сайтов, закладок и заметок.

## Реализованные разделы

| Раздел | Описание |
|---|---|
| **Главная** | Карусель с крупными постерами и автопрокруткой; «Продолжить просмотр» и «Продолжить чтение»; «Для вас» по любимым жанрам; «Сейчас популярно»; поиск с панелью подсказок |
| **Каталог** | Поиск с задержкой ввода (debounce), категории, фильтры, сортировка, бесконечная прокрутка по страницам, скелетоны загрузки |
| **Страница тайтла** | Постер, рейтинг, жанры, избранное, «Поделиться»; кнопка «Смотреть / Читать» с нужной серией; вкладки «Описание», «Серии / Главы», «Отзывы», «Похожее»; своя оценка и отзывы |
| **Библиотека** | Аниме и манга отдельно, списки по статусам, поиск и сортировка, быстрые действия |
| **Плеер и читалка (демо)** | Имитируют просмотр и чтение, чтобы работал сценарий «посмотрел, прогресс сохранился, очки начислены» |
| **Профиль** | Фото аватара и фона из галереи **или с камеры** с настройкой масштаба, положения, затемнения и размытия; рамки, фоны, значки; уровень и опыт; витрины; достижения |
| **Вход и облако** | Регистрация и вход по почте (Firebase Auth); после входа избранное и библиотека синхронизируются с Firestore |
| **Рядом** | Карта Google Maps с кинотеатрами, книжными и магазинами игр рядом (геолокация + OpenStreetMap) |
| **Push-уведомления** | Firebase Cloud Messaging; в настройках виден статус и токен устройства |
| **Датчики** | Встряхни телефон на главных вкладках, и откроется случайный тайтл (акселерометр) |
| **Энергосбережение** | Нативный код на Kotlin определяет заряд и режим экономии; при экономии карусель не листается сама |
| **Меню и настройки** | Тёмная, светлая и системная темы; акцентный цвет; язык; проверка Crashlytics |
| **Работа без сети** | Библиотека, избранное и оценки лежат на устройстве; последние ответы API сохраняются на диск; ошибки с кнопкой «Повторить» |

## Известные ограничения

- **iOS** не настроен для карт (нет ключа в `AppDelegate`), геолокации, камеры и push (нет строк разрешений и entitlements). Остальной интерфейс работает.
- Сортировка «по названию» в каталоге работает только внутри уже загруженных страниц (API не умеет сортировать по названию на сервере).
- Оценки и отзывы хранятся только на устройстве и не синхронизируются с облаком.
- Данные OpenStreetMap в некоторых районах неполны, поэтому рядом может ничего не найтись.
- Описания тайтлов приходят от Kitsu на английском.
- Переведены на английский нижнее меню, меню и настройки; остальные экраны только на русском.
